📌 Overview

Crypto is a Blockchain Analytical Tool built to analyze cryptocurrency transactions and extract meaningful insights from blockchain data.

It enables users to:

Understand transaction flows
Detect anomalies or suspicious activity
Visualize blockchain data effectively
Perform structured analytics on crypto datasets
🎯 Key Features
🔍 Transaction Analysis
📊 Data Visualization

⚙️ Installation
1️⃣ Clone the Repository
git clone https://github.com/Sugan-166/Crypto.git
cd Crypto
2️⃣ Create Virtual Environment
python -m venv venv
3️⃣ Activate Environment

Windows:

venv\Scripts\activate

Linux / Mac:

source venv/bin/activate
4️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Usage

Run the project using:

python main.py
